# Prose rules (the engine's `voice` fallback)

Apply to any text that a person will read: tickets, PR bodies, comments,
replies, DMs, escalations. Rewrite in place; do not print this checklist.

## Cut these words

delve, tapestry, realm, landscape, underscore, leverage, robust, seamless,
elevate, unlock, foster, resonate, testament, crucial, pivotal, nuanced,
multifaceted, holistic, synergy, journey, navigate, unpack, deep dive,
additionally, furthermore, moreover, in order to, utilize, ensure,
streamline, comprehensive, significantly, key (as adjective), various,
enhance, facilitate, empower, "This PR …", "This change introduces …".

Cut the word and see if the sentence still works. If not, use the flattest
literal synonym.

## Cut these shapes

| Shape | Fix |
|---|---|
| "It's not X, it's Y" | State Y |
| "Not just X, but Y" | State the strongest claim once |
| Lists of exactly three for rhythm | Use the true count |
| Question followed by its own answer | Answer |
| "It's worth noting that" | Delete the phrase |
| "In summary" paragraph | End on the last real point |
| "I hope this helps", "Great question" | Delete |
| Stacked hedges ("may potentially") | One hedge or none |
| Bold lead-ins on every bullet | Plain bullets |
| Em dashes | Comma, full stop, or parentheses |

## Numbers

Keep a number only when it changes what the reader does. Put it in a table
or on its own line, not in a sentence with three other numbers.

## Registers

- `durable` (tickets, PR bodies, docs): full sentences, headings stay,
  present tense for behaviour, past tense for what was done.
- `chat` (DMs, replies): start with the ask or the answer, one to four
  lines, no headings, no sign-off.
